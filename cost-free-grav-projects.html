More Cost-Free Grav Projects

Full CMS

More free, open-source Grav projects: four plugins – diagrams and math written as text, an “Edit this Page” link for almost any Grav site, and a Site ReadMe in Admin 2 – and a documentation site. For open guides and books, see Grav Open Publishing Space; for courses, Grav Open Course Hub – or every Grav project in Grav CMS Projects at a Glance.

Grav (15.7k ★s) is a flat-file CMS that stores content as plain Markdown files instead of a database, edited through a browser-based Admin panel, and runs on any standard web host with PHP 8.3+ (or PHP 8.0.2+ for Grav 1.7).

Jump to: Mermaid Plugin · LaTeX Math Plugin · Git Page Link Plugin · Admin2 Site ReadMe Plugin · Learn2 with Git Sync

Mermaid Plugin

The Mermaid Plugin works with most Grav themes and sites, on Grav 2 and 1.7. It draws Mermaid diagrams – flowcharts, timelines, sequence diagrams and more – from text in a page, matching the theme’s light or dark mode. Diagrams written as text are easy to revise and remix, are covered by the page’s license, and can include a title and description for screen readers.

→ Demo GitHub

LaTeX Math Plugin

The LaTeX Math Plugin works with most Grav themes and sites, on Grav 2 and 1.7. It draws math written as LaTeX – formulas, equations and chemistry – with your choice of KaTeX or MathJax, matching the theme’s light or dark mode. Math written as text is easy to revise and remix, is covered by the page’s license, and is read by screen readers.

→ Demo GitHub

Git Page Link Plugin

The Git Page Link Plugin works with most Grav themes and sites. It adds an "Edit this Page" link back to the Markdown source, for open authoring and community contribution.

→ Demo GitHub

Admin2 Site ReadMe Plugin

The Admin2 Site ReadMe Plugin works with Grav 2 and its new Admin 2 panel. It adds a Site ReadMe item to the Admin 2 sidebar, showing a Markdown file such as a README on GitHub, so the people editing a site can read its how-tos and guidelines right where they work.

→ GitHub

Grav Learn2 with Git Sync

An open documentation site on the free Learn2 theme – a place to publish guides, manuals, or course notes that others can read and help improve, with support for a Docs-as-Code approach.

  • Chapters with numbered sidebar navigation, previous/next page arrows & reading history
  • Instant search, plus tag-aware full-text search with the included TNTSearch plugin
  • Atom/RSS feeds so readers can follow documentation changes
  • Git Sync with “Edit this Page” links for open, collaborative authoring
