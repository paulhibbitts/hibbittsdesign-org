Cost-Free Grav Projects

Full CMS

The Cost-Free Grav Projects are four fully open-source skeletons, built on the newly released Grav 2 (with Grav 1.7 versions also available), for open guides and books, course hubs, multi-course sites, and documentation – well suited to OER and other open educational resources. Grav (15.7k ★s) is a flat-file CMS that stores content as plain Markdown files instead of a database, edited through a browser-based Admin panel, and runs on any standard web host with PHP 8.3+ (or PHP 8.0.2+ for the Grav 1.7 versions).

Each shares the same portable Markdown files and optional Git Sync – Publishing Space, Course Hub, and MultiCourse Hub also support LMS-ready embedding for platforms like Canvas and Moodle. All four were refreshed in 2026 with a Dark Mode option, and the course hubs also gained the cleaner 2026 Modern look, with a tinted NavBar in each course’s colour, and accessibility improvements.

★ 27 Grav 2 & 1.7

Grav Open Publishing Space

An open guide or book site – such as a course reader, handbook, or short open textbook – with a blog and almost any other Grav page alongside it.

  • Guides with section cards, parts, reading progress, Keep My Place, Learning Objectives & OER attribution
  • The same core page types and settings as Grav Helios Open Reader, so guides can move between the two
  • Pressbooks books can be converted with the free Pressbooks Converter (beta)
  • A ready-to-go blog with featured posts, tags, archives & Atom/RSS feeds
  • Search with highlighted results, including a search box on each guide
  • Built on Quark 2, Grav 2’s modern theme, with Light, Dark & Auto modes (Quark for Grav 1.7)

★ 47 Grav 2 & 1.7

Grav Open Course Hub

A free, open home on the web for a single course, inside or outside your LMS. Content lives as plain Markdown files, with a browser-based Admin panel for editing and no database required.

  • Weekly units listed newest first, “What’s Happening This Week” reminders, plus schedule, resources & syllabus pages
  • Course content shortcodes and GitHub-style alerts, the same as in Grav Helios Course Hub, so content using them can move there later
  • Course search, plus Google Slides, H5P, PDF & link preview embeds
  • Embeds in Canvas, Moodle and other LMSs – no special integration needed
  • 2026 Modern style with a tinted NavBar in your course colour, plus optional Dark Mode
  • Git Sync with “Edit this Page” links for open, collaborative authoring

★ 6 Grav 2 & 1.7

Grav Open MultiCourse Hub

The same Course Hub structure, plus a top-level course-selection layer for managing several courses from one site, inside or outside your LMS – each course with its own look, and content you can share between them.

  • A homepage of course cards, with each course getting its own navigation, header image, sidebar, footer, NavBar colour & favicon
  • Share any page or section between courses with the included Page Inject plugin
  • Course content shortcodes and GitHub-style alerts, the same as in Grav Helios Course Hub, so content using them can move there later
  • Search within each course, with an optional all-courses search on the homepage
  • Embeds in Canvas, Moodle and other LMSs – no special integration needed
  • 2026 Modern style with a tinted NavBar in each course’s colour, plus optional Dark Mode

★ 38 Grav 2 & 1.7

Grav Learn2 with Git Sync

An open documentation site on the free Learn2 theme – a place to publish guides, manuals, or course notes that others can read and help improve, with support for a Docs-as-Code approach.

  • Chapters with numbered sidebar navigation, previous/next page arrows & reading history
  • Instant search, plus tag-aware full-text search with the included TNTSearch plugin
  • Atom/RSS feeds so readers can follow documentation changes
  • Git Sync with “Edit this Page” links for open, collaborative authoring
→ See the demo Download View on GitHub

All four share the same open, portable Markdown files, a browser-based Admin panel, and optional Git Sync for version-controlled collaboration.

Also Free: Git Page Link Plugin

The Git Page Link Plugin works with most Grav themes – not just these four skeletons. It adds an "Edit this Page" link back to the Markdown source, for open authoring and community contribution.

Free or Grav Helios?

Grav Helios Open Reader and Grav Helios Course Hub are the premium siblings of these skeletons, built on the Grav Premium Helios theme (a one-time license) with a more refined, app-like design. Content moves easily between Open Publishing Space and Open Reader, and between the course hubs with a few adjustments, so you can start free and move later.
